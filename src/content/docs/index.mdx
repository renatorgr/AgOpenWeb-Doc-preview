## Want to contribute?

AgOpenWeb is community built. You can help by:

- Improving this documentation: every page has an **Edit page** link at the
  bottom
- Submitting issues or fixes to the
  [codebase](https://github.com/AgOpenGPS-Official/AgOpenWeb)
- Sharing your own build tips and guides on
  [Discourse](https://discourse.agopengps.com)
