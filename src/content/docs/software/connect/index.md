This section takes you from a running AgOpenWeb to a tractor it can see: the
modules answering on the network, the GPS receiver giving a position, and RTK
corrections arriving.

Everything here is under **Network IO**, the last button on the left bar.

Before you start, the modules must be cabled to the computer that runs
AgOpenWeb. See
[What you need](/software/what-you-need/#an-ethernet-cable-to-the-modules).

A good order to work in:

1. [Network IO](/software/connect/network-io/): check that every module
   answers.
2. [GPS receivers](/software/connect/gps-receivers/): check that the receiver
   sends what AgOpenWeb reads.
3. [RTK corrections (NTRIP)](/software/connect/ntrip/): enter your correction
   service.
4. [System Data](/software/connect/system-data/): read the quality of what
   arrives.
