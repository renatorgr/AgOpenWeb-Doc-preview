All downloads are on the
[AgOpenWeb releases page](https://github.com/AgOpenGPS-Official/AgOpenWeb/releases).
Pick the file for your device:

| Device               | File                                              | Guide                                 |
| -------------------- | ------------------------------------------------- | ------------------------------------- |
| Windows tablet or PC | `agopenweb-win-x64.zip`                           | [Windows](/software/install/windows/) |
| Mac (Apple silicon)  | `agopenweb-macos-arm64.dmg`                       | [macOS](/software/install/macos/)     |
| Linux, with a window | `agopenweb-launcher-linux-x64.tar.gz` or `-arm64` | [Linux](/software/install/linux/)     |
| Linux, no display    | `agopenweb-linux-x64.tar.gz` or `-arm64`          | [Linux](/software/install/linux/)     |
| Android tablet       | `agopenweb-android.apk`                           | [Android](/software/install/android/) |

Every download is complete in itself. You do not need to install .NET or any
other framework first.

## Which release?

The releases page has numbered versions (`v26.7.7`, for example) and a build
named **Beta** that is rebuilt each day the developers have made changes. A
numbered version stays as it is; the beta has the newest fixes and the newest
mistakes.

## Where your data lives

Fields, vehicle and tool profiles and settings are kept apart from the program,
in `Documents/AgOpenWeb` (for the Linux daemon, `/home/agopenweb/AgOpenWeb/`).
Replacing the program with a newer version leaves them alone.
